# Run and deploy your AI Studio app

This contains everything you need to run your app locally.你

View your app in AI Studio: https://ai.studio/apps/d783940d-de4b-486e-9210-9a5edbbb5e94

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
